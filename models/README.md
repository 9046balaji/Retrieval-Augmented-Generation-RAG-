# Models Overview & Specification

This folder and document outline the machine learning models used in the **Multi-Query Retrieval-Augmented Generation (RAG)** pipeline.

---

## 1. Dense Embedding Model

### `BAAI/bge-base-en-v1.5`
* **Type**: Dense Text Embedding Model (Transformer Encoder)
* **Storage Location**: `models/bge-base-en-v1.5/`
* **Format**: SafeTensors (`model.safetensors`, ~438 MB)
* **Architecture**: BERT-based encoder with mean pooling and L2 vector normalization.

### Technical Specifications:
| Parameter | Value | Description |
| :--- | :--- | :--- |
| **Embedding Dimension** | `768` | Size of dense output vector |
| **Max Sequence Length** | `512` tokens | Truncation limit for text passages |
| **Similarity Metric** | Cosine Similarity | Used by ChromaDB HNSW index (`hnsw:space: "cosine"`) |
| **Query Instruction** | Built-in | Instruction prefix applied for retrieval queries |
| **Hardware Execution** | PyTorch / GPU / CPU | Offline inference without external cloud dependencies |

### Roles in the Pipeline:
1. **Document Indexing**: Vectorizes 5,183 scientific papers from the BEIR SciFact corpus into 768-dimensional coordinates in ChromaDB.
2. **Multi-Query Retrieval**: Vectorizes all 4 expanded queries generated by MedGemma concurrently to perform parallel dense vector searches.

## 2. Generative Large Language Model (LLM)

### `MedGemma 1.5 4B IT` (`medgemma4b:latest`)
* **Type**: Instruction-Tuned Biomedical Large Language Model
* **Developer**: Google Health / Gemma Team
* **Serving Runtime**: Local Ollama Server (`http://localhost:11434/api/generate`)
* **Parameters**: 4 Billion
* **Quantization**: 4-bit / 8-bit quantized (GGUF format via Ollama)

### Runtime Configurations (`src/config.py`):
| Parameter | Value | Purpose |
| :--- | :--- | :--- |
| **Context Window (`num_ctx`)** | `16384` (16k tokens) | Prevents context truncation when ingesting 20 retrieved candidate passages |
| **Generation Temperature** | `0.2` | Minimizes creativity to enforce strict evidence grounding |
| **Expansion Temperature** | `0.7` | Promotes semantic diversity across the 4 query search angles |
| **Judge Temperature** | `0.1` | Ensures consistent, objective scoring for faithfulness evaluations |

### Roles in the Pipeline:
1. **Multi-Query Transformation Engine**:
   - Takes a user's single question and decomposes it into **4 orthogonal search perspectives**:
     - *Q1*: Direct mechanism & core keywords.
     - *Q2*: Molecular pathways & biochemical processes.
     - *Q3*: Clinical phenotypes & downstream effects.
     - *Q4*: Associated genes, targets, and biomarkers.
2. **Strict Grounded Generator**:
   - Synthesizes the final answer using **only** the top deduplicated passages returned from Reciprocal Rank Fusion ($k=60$).
   - Mandates inline bracketed citations (`[Document <id>]`) for every claim.
   - Explicitly refuses to hallucinate facts missing from the retrieved context.
3. **LLM-as-a-Judge**:
   - Performs automated evaluation of the synthesized answer against the retrieved context.
   - Evaluates Faithfulness (1.0 to 5.0), Context Utilization, and Query Relevance.

## 3. Directory Layout

```
models/
└── bge-base-en-v1.5/
    ├── config.json                     # Model architecture configuration
    ├── model.safetensors               # Model weights (438 MB)
    ├── modules.json                    # SentenceTransformers pipeline definition
    ├── tokenizer.json                  # WordPiece tokenizer vocabulary & merges
    ├── vocab.txt                       # Raw vocabulary list
    ├── 1_Pooling/                      # Mean pooling layer definition
    └── 2_Normalize/                    # L2 normalization layer definition
```

## 4. How to Verify Local Models

### Verify Ollama MedGemma:
```powershell
ollama list
# Output should show: medgemma4b:latest
```

### Verify Offline Embedding Model:
```powershell
python -c "from sentence_transformers import SentenceTransformer; m = SentenceTransformer('models/bge-base-en-v1.5'); print('Model loaded successfully! Vector dim:', m.get_sentence_embedding_dimension())"
# Output should show: Vector dim: 768
```
